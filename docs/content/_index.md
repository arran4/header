# header documentation

**header** is a Go CLI and library for extracting, checking and editing website metadata. It understands Open Graph, Twitter Cards, JSON-LD, App Links, and page links, and can generate preview images.

- [Getting started](docs/getting-started/) — install the tool and inspect your first page.
- [How-to guides](docs/how-to/) — perform focused tasks.
- [Concepts](docs/concepts/) — understand extraction, rendering and validation.
- [CLI reference](docs/reference/) — commands and output styles.
- [Contributing](docs/contributing/) — development and testing.

Source code: [arran4/header](https://github.com/arran4/header). Go package API: [pkg.go.dev/github.com/arran4/header](https://pkg.go.dev/github.com/arran4/header).
