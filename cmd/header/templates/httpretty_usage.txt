Usage: header httpretty [flags...] <urlStr>

Fetch a URL and print HTTP requests and responses using httpretty.

Subcommands:
    help         Print this help message
    usage        Print this usage message


Flags:
    --user-agent, --Agent string     (default: "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/91.0.4472.124 Safari/537.36")   The User header to use when fetching URLs
    --follow-meta-redirects                                                                                                                                             Follow meta refresh redirects
    --update-referer                 (default: true)                                                                                                                    Update Referer header on redirect
    --store-cookies                  (default: true)                                                                                                                    Store cookies across redirects
    --redirect-limit int             (default: 20)                                                                                                                      Maximum number of redirects to follow
    --redirect-delay time.Duration   (default: 0)                                                                                                                       Delay between redirects (e.g. 1s, 500ms)

Positional Arguments:
    <urlStr>   (required) URL to fetch
