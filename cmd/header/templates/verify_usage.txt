Usage: header verify [flags...] <urlStr>

Checks all the urls, and other details, it's a subset of the lint rules that is mostly concerned with valid info.

Subcommands:
    help         Print this help message
    usage        Print this usage message


Flags:
    --user-agent, --Agent string   (default: "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/91.0.4472.124 Safari/537.36")   The User header to use when fetching URLs
    --httpretty                                                                                                                                                       Print HTTP requests and responses

Positional Arguments:
    <urlStr>   (required) URL to verify
